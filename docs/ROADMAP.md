# Roadmap

## Foundation
- [x] Next.js, TypeScript and Tailwind application shell
- [x] PWA manifest
- [x] Local media selection UI (no upload)
- [ ] App icons and offline service worker
- [ ] CI: lint, typecheck and production build

## V1 — Short-form video workflow
- [ ] Local project creation and versioned project format
- [ ] Media metadata and thumbnail extraction
- [ ] Audio extraction and transcription
- [ ] Candidate clip detection with explainable scoring
- [ ] Vertical 9:16 crop and subtitle editor
- [ ] Basic multi-track timeline
- [ ] MP4 export with browser capability checks
- [ ] Project backup and restore

## V1.5 — Creative tools
- [ ] Audio cleanup and mixing
- [ ] Image resize, crop and color adjustments
- [ ] Reusable title and subtitle templates
- [ ] Social format presets

## V2 — Extensibility
- [ ] Permission-based plugin SDK
- [ ] Optional local AI model catalog with license metadata
- [ ] Optional external AI adapters with per-action consent
- [ ] Community templates and localization

## Release gates
- No media upload without explicit consent.
- No essential paid feature or advertising.
- Third-party code, models and assets must have verified compatible licenses.
- Test on desktop and mobile browsers, including low-memory devices.
